1Introduction

This chapter tells you what Stratum 4D does, which layouts it has, and how to use this manual.

What Stratum 4D is

Stratum 4D is a planning and 4D simulation tool for construction projects. It reads a schedule from Primavera P6 or Microsoft Project. It can also read a 3D building model in the IFC format.

You link the model elements to the activities of the schedule. Stratum then shows the construction sequence in 3D, day by day. You can calculate the schedule, record progress, compare against a baseline and make reports.

The three layouts

Stratum 4D has three layouts. All three layouts use the same calculation engine and the same project data. When you change the layout, the open project stays open.

  • The P6 layout looks and works like Primavera P6 Professional.
  • The Project layout looks and works like Microsoft Project.
  • The 4D layout shows the 3D model, the Gantt chart and the playback timeline together.

To change the layout

  1. On the top bar, click P6, Project or 4D.The new layout opens with the same project.
  2. Alternatively, push Ctrl+Alt+1, 2 or 3.

The sample projects

Stratum 4D has two sample projects. You can use them to learn the software without your own files. The two sample projects are fictional.

Sample projectContents
220 kV GIS substation (UAE)46 activities on a UAE 6-day calendar, costs in AED, resources, a baseline and a 3D model with 202 elements.
Small RC buildingA small concrete building with 14 activities and a 3D model. Use it for a fast first test.

This manual uses the 220 kV GIS substation project for most examples.

How to use this manual

This manual is written in ASD-STE100 Simplified Technical English. Each chapter starts with its purpose. Then it gives a description and the procedures.

  • A procedure is a numbered list of steps. Do the steps in the given order.
  • A line that starts with "Result" tells you what you see after the step.
  • Names of buttons, menus and fields are in bold blue.
  • Keys are shown as Ctrl+S. Push the keys at the same time.
A NOTE gives information that helps you.
A CAUTION tells you about a risk of loss of data.

2Installation

This chapter tells you how to install Stratum 4D on Windows, macOS, Linux and Android, and how to use it in a web browser.

Versions of Stratum 4D

Stratum 4D is available as a desktop application, an Android application and a web application. All versions have the same layouts and the same calculations.

The desktop application can connect to Primavera P6 and can send reports by email. The web application and the Android application cannot connect to P6.

Get the installation files

The installation files are on the releases page of Stratum 4D on GitHub. Each release has one file for each type of device.

  1. Open the releases page: github.com/xunaidlnt-sudo/stratum-4d/releases.
  2. Find the latest release at the top of the page.
  3. Under Assets, click the file for your device.The file goes into the Downloads folder.

Install on Windows

Use the file that ends with -win-x64.exe. Windows 10 and Windows 11 (64-bit) are supported.

The installer does not have a code signature yet. Thus Windows SmartScreen can show the message "Windows protected your PC".
  1. Double-click the file Stratum-4D-<version>-win-x64.exe.
  2. If SmartScreen shows a message, click More info.
  3. Click Run anyway.
  4. Select the folder for the installation, or keep the default folder.
  5. Click Install.The installer adds Stratum 4D to the Start menu and to the desktop.
  6. Click Finish.Stratum 4D starts.

After the installation, Windows opens .xer and .ifc files in Stratum 4D when you double-click them.

Install on macOS

There are two files for macOS. Use -mac-arm64.dmg on a Mac with Apple silicon (M1 or later). Use -mac-x64.dmg on a Mac with an Intel processor.

  1. Double-click the .dmg file.A window opens with the Stratum 4D icon.
  2. Drag the Stratum 4D icon to the Applications folder.
  3. Open the Applications folder.
  4. Right-click Stratum 4D and click Open.
  5. In the message, click Open again.Stratum 4D starts. Next time, you can open it as usual.

Install on Linux

There are two files for Linux. The .AppImage file operates on most distributions. The .deb file is for Debian and Ubuntu.

To use the AppImage file

  1. Open a terminal in the Downloads folder.
  2. Type chmod +x Stratum-4D-*.AppImage and push Enter.
  3. Double-click the AppImage file.Stratum 4D starts.

To install the .deb file

  1. Open a terminal in the Downloads folder.
  2. Type sudo apt install ./Stratum-4D-*.deb and push Enter.
  3. Start Stratum 4D from the applications menu.

Install on Android

Use the file that ends with -android.apk. The application is for phones and tablets with Android 8 or later.

  1. On the phone or tablet, open the releases page and download the .apk file.
  2. Open the file from the download notification.
  3. If Android asks for permission to install from this source, give the permission.
  4. Tap Install.
  5. Tap Open.Stratum 4D starts.
To share a cloud folder (Google Drive or OneDrive) with a team on a tablet, use the web application. Chapter 4 tells you about shared folders.

Use the web application

The web application operates in Chrome, Edge, Firefox and Safari. It is not necessary to install it. The web application keeps your projects in the storage of the browser on that computer.

  1. Open the address of the web application that you got from Miqyas Labs.
  2. Type your user name and password.
  3. Click Sign in.Stratum 4D opens. At the first start, the setup steps of chapter 3 open.

To install the web application as an application

  1. Open the web application in Chrome or Edge.
  2. In the address bar, click the install icon.
  3. Click Install.Stratum 4D opens in its own window, with an icon on the desktop.
If you clear the data of the browser, the projects in the browser storage are deleted. Save a project file or use a shared folder to keep a copy (chapter 4).

Update to a new release

To update the desktop application, install the new release over the old release. Your projects and settings stay. The web application updates when you open it again.

Remove Stratum 4D

  • Windows: open Settings › Apps, select Stratum 4D and click Uninstall.
  • macOS: drag Stratum 4D from the Applications folder to the Bin.
  • Linux: delete the AppImage file, or type sudo apt remove stratum-4d.
  • Android: touch and hold the icon, then tap Uninstall.
The projects in the database stay on the computer after you remove the application. Delete them only if you have a copy.

4Projects and files

This chapter tells you how to open, import, save and export projects, and where Stratum 4D keeps them.

Projects and files

In this manual, a project is a schedule that Stratum 4D keeps in its database. A file is a file on the disk, for example an XER file from P6.

You import a file to make a project. You export a project to make a file. The project database keeps each saved version of a project.

Where Stratum 4D keeps the projects

StorageWhereWho can open the projects
Desktop applicationA SQLite file in your user folderYou, on this computer
Web applicationThe storage of the browserYou, in this browser on this computer
Cloud folderA Google Drive or OneDrive folderAll persons with edit access to the folder
Stratum ServerA PostgreSQL databaseAll users of the server, by their role

Each save gets a version number. If a different person saved the project after you opened it, Stratum 4D does not save over that version. It gives you the option Save as new.

Import a schedule file

Stratum 4D can import these schedule files:

  • Primavera P6 XER files (.xer), with activities, WBS, logic, codes, user fields, calendars, resources, costs and baselines.
  • Microsoft Project XML files (.xml). In Microsoft Project, use File › Save As › XML Format to make this file.
  • Microsoft Excel files (.xlsx) that you exported from Stratum 4D and changed.
Stratum 4D cannot open Microsoft Project .mpp files. Save the file as XML in Microsoft Project first.

To import a schedule in the P6 layout

  1. Click File › Import….
  2. Select the .xer or .xml file.
  3. Click Open.The schedule opens as a new project.

To import a schedule in the Project layout

  1. Click File.
  2. Click Open.
  3. Click Import XER / Microsoft Project XML.
  4. Select the file and click Open.

To import a new version of the same schedule

Each week, you can import the new XER over the open project. Stratum 4D keeps the model links because it finds each activity by its Activity ID. If you click Cancel at step 3, the file opens as a new project.

  1. Open the project.
  2. Import the new XER file as usual.
  3. Stratum 4D asks "Update the open schedule with this file?". Click OK.The Check tab lists the changes: finish slip, new and deleted activities, and changes of status.

Open and save a project

To open a project from the database

  1. Click Projects (P6 and 4D layouts), or File › Open › Projects (Project layout).
  2. Select the project.
  3. Click Open.

To save a project

  1. Push Ctrl+S, or click Save.Stratum 4D saves a new version of the project in the database.

Stratum 4D also saves your work in the background every few seconds. If the application closes without a save, it asks you to restore the work at the next start.

Export a project

ExportUse it for
P6 XERImport into Primavera P6. Use Update Existing Project in P6 to bring the dates back.
Microsoft Project XMLOpen in Microsoft Project 2010 or later.
Excel (.xlsx) or CSVChange data in Excel, or make your own reports.
Stratum project file (.stratum.json)Move a project, with its model links, to a different computer.

To export a project

  1. In the P6 layout, click File › Export…. In the Project layout, click File › Save As.
  2. Click the type of file.The file goes into the Downloads folder.
Before you import an exported XER into P6, make a backup of the P6 project. An import with Update Existing Project changes the project in P6.

Share projects with a cloud folder

A team can use one Google Drive or OneDrive folder as a shared database. All persons with edit access to the folder work on the same projects. Stratum 4D does a check before each save, so no person saves over newer work.

  1. Click the gear icon (Settings).
  2. Click the Data & sign-in tab.
  3. Under Cloud folder, click Google Drive or OneDrive.
  4. Sign in to the account.A list of your folders opens.
  5. Open the folder that your team shares.
  6. Click Use "<folder>" as the Stratum folder.The projects in the folder show in Projects.
Your administrator must first register Stratum 4D with Google or Microsoft. The file docs/CLOUD_STORAGE.md tells the administrator how to do this.

This chapter tells you how to use the P6 layout to plan, schedule, update and check a project.

Make the activities

To add an activity

  1. In the activity table, select a row in the applicable WBS.
  2. Push Ins, or click Edit › Add.A new activity row shows below the selected row.
  3. Type the Activity Name.
  4. Type the Original Duration in days.

To link activities

  1. Select the activities in the sequence of the work. Hold Ctrl to select more than one.
  2. Push Ctrl+L, or click Edit › Link Activities.Each activity becomes the predecessor of the next activity, with a Finish to Start relationship.

To set a different relationship type (FS, SS, FF or SF) or a lag, open the Predecessors tab in the bottom pane. Then change the type or the lag of the relationship.

To assign resources

  1. Select the activity.
  2. Click Edit › Assign Resources….
  3. In the row of the resource, click Assign.The resource is assigned to all the selected activities.
  4. Click Close.
  5. In the Resources tab, type the Budgeted Units for each resource.

Schedule the project

The scheduler calculates the early and late dates and the total float of each activity. It uses the logic, the durations, the calendars and the constraints. It starts at the data date.

To schedule the project

  1. Push F9, or click Project › Schedule….The Schedule dialog opens.
  2. Make sure that Current Data Date is correct.
  3. Click Schedule.The dates and the float change. The critical activities show in red.
  4. To see the result of the calculation, click View Log.

To change the rules of the calculation, click Options… in the Schedule dialog. For example, you can set retained logic or progress override, and the definition of a critical activity.

Stratum 4D uses the same calculation rules as P6. If you import an XER file and schedule it with the same options, the dates are the same as in P6. If a date is different, look at the schedule log first.

Set and compare baselines

A baseline is a copy of the project at one time. You compare the current schedule with the baseline to see the slip.

To make a baseline

  1. Click Project › Maintain Baselines….
  2. Click Add.A copy of the current project becomes a new baseline.
  3. Type a name for the baseline.
  4. To compare the project with this baseline, click Assign as Project Baseline.
  5. Click Close.

To see the baseline bars on the Gantt chart, click View › Show Baseline Bars. To use a baseline from a different file, click Assign from file… and select the XER or XML file.

Update the progress

Each update period, you record the actual progress. Then you move the data date and schedule again. Figure 5-4 shows the cycle.

To record the progress of an activity

  1. Select the activity.
  2. In the bottom pane, click the Status tab.
  3. Set Status to In progress or Complete.
  4. Type the Actual start date. For a complete activity, also type the Actual finish date.
  5. For an activity in progress, type the % complete and the Remaining (days).

To update all the activities as planned

Use this procedure if the work went as planned. It sets the actual dates and the progress from the planned dates.

  1. Click Tools › Update Progress….
  2. Type the New data date.
  3. Select All activities, or Selected activities only.
  4. Click Apply.
  5. Push F9 to schedule the project.
Update Progress changes the actual dates of many activities. Do a check of the result before you send the schedule to other persons. To go back, push Ctrl+Z.

Check the schedule

To do a quality check

  1. Click Project › Check Schedule….The dialog shows each check with the number of activities that do not pass.
  2. Click a check to see its activities.
  3. Correct the activities. Then do the check again.

The checks include missing predecessors and successors, hard constraints, negative float, high float, long durations, leads and lags.

To compare two schedules

  1. Click Tools › Claim Digger (compare schedules)….
  2. Open the project of this update. Stratum 4D uses it as the Current schedule.
  3. For the Base schedule, select a stored baseline. Or click Choose… and select the file of the last update.The report lists the changed, added and deleted activities, and the changed relationships.
  4. To keep the report, click the download button.

Change the view

To change many activities at the same time, use Tools › Global Change…. Make a filter first, so that the change applies only to the correct activities.

Send the result

If you imported the project from a P6 connection, click Project › Send Progress to P6 to send the progress directly. On a Stratum Server, an administrator can approve this update first (Chapter 10).

To send the schedule back to P6 as a file, click File › Export… (XER). To send it to Microsoft Project, click File › Export… (Microsoft Project XML). To print, push Ctrl+P. Chapter 4 gives the procedures.

Auto scheduled and manually scheduled tasks

An auto scheduled task gets its dates from the logic and the calendar. A manually scheduled task keeps the dates that you type. The scheduler does not move it.

To change the mode, select the tasks and click Task › Auto Schedule or Task › Manually Schedule. The mode for new tasks shows on the status bar.

The P6 layout and the 4D layout show a manually scheduled task as an activity with fixed dates. If you export the project to XER, P6 schedules the task as usual.

Task information

Double-click a task, or push Shift+F2, to open the Task Information dialog. The dialog has these tabs: General, Predecessors, Resources, Advanced, Notes and Custom Fields.

On the Advanced tab, you set the Deadline, the Constraint type, the Task type and Effort driven.

Work, duration and units

When you assign a resource to a task, the Project layout uses this rule: Work = Duration × Units. The task type tells which value stays the same when you change a different value. Figure 6-3 shows the three task types.

To assign a resource

  1. Select the task.
  2. Click Resource › Assign Resources.
  3. Select the resource and type the units, for example 200% for two persons.
  4. Click Assign, then Close.

To see the work of each resource for each day, click View › Task Usage or View › Resource Usage. To see the resources as rows with their tasks, click View › Team Planner.

A resource that has too much work shows in red. To find it, click Resource › Next Overallocation. To solve it, click Resource › Level All. To remove the result of the levelling, click Resource › Clear Leveling.

Calendars

To change the work hours and the holidays

  1. Click Project › Change Working Time.
  2. Select the calendar.
  3. To add a holiday, type a Name, a Start and a Finish on the Exceptions tab.
  4. To change the work week, use the Work Weeks tab.
  5. Click OK.

Split tasks and repeated tasks

To stop a task and start it again later, click Task › Split Task. Then click in the bar at the point of the stop. The task gets a gap of one day at that point. Drag the second part of the bar to the new start date.

To add a task that occurs at regular intervals, for example a weekly progress review, click Task › Recurring Task. Type the pattern and the number of occurrences.

Baseline and progress

To set the baseline

  1. Click Project › Set Baseline.
  2. Select Entire Project or Selected Tasks.
  3. Click OK.

To update the project to a status date

  1. Click Project › Update Project.
  2. Select Update work as complete through and type the date.
  3. Click OK.The tasks before the date show as complete. The tasks that cross the date show as in progress.

To record the progress of one task, select the task and click Task › Mark on Track, or type the % Complete in the task sheet.

Save for Microsoft Project

To make a file for Microsoft Project, click File › Save As and select Save as MS Project XML. Microsoft Project opens this file directly.

The XML file keeps the tasks, the summary tasks, the logic, the calendars, the resources, the assignments, the baseline and the custom fields.

7The 4D layout

This chapter tells you how to link a 3D model to a schedule, and how to play, check and show the 4D simulation.

What a 4D simulation is

A 4D simulation shows the 3D model on the dates of the schedule. Each element of the model shows when its activity starts, and becomes complete when its activity finishes. You can see the sequence of the work before the work starts on site.

Figure 7-1 shows the five steps to make a 4D simulation.

Parts of the 4D layout

PartWhereUse
3D viewCenterThe model on the playback date
Side panelRightSelection, Rules, Tools, Profiles, Display and Check tabs
Gantt chartBottomThe activities, with a line on the playback date
Playback barBelow the 3D viewPlay, pause, speed, and the buttons to go back or forward

Load the schedule and the model

  1. Import the schedule (XER or XML). Chapter 4 gives the procedure.
  2. Click Import model on the toolbar, or Import 3D model… in the side panel.
  3. Select the model file and click Open.The model shows in the 3D view. Large models can take some minutes.
FormatWhat Stratum 4D reads
IFC (.ifc, IFC2x3 and IFC4)Each building element, with its properties, quantities and storey
glTF (.glb, .gltf)Each mesh, with its name, its parent node and its custom properties ("extras")
OBJ, STL, FBXEach mesh, with its name. FBX also gives its custom properties.

If the custom properties of a mesh have an identifier (for example GlobalId), Stratum 4D uses it. Then the links stay when you export the model again. A .gltf file must hold its data in the file. If it does not, export a .glb file.

If a model is very large, Stratum 4D thinks that it is in millimeters or centimeters. It then changes the scale to meters and tells you in the status bar.
To try the 4D layout without your own files, open File and select Sample: 220 kV GIS substation (UAE).

Link the model to the schedule

Each link connects one element of the model to one activity. There are two methods: rules and manual links.

To link with rules

A rule compares a property of the element with a field of the activity. For example, the rule can link each element where the property Zone is the same as the activity code Zone.

  1. In the side panel, click the Rules tab.
  2. Click Auto-detect. Stratum 4D finds the properties that agree with the activity data and proposes rules.
  3. Examine the proposed rules. To make a different rule, click New rule.
  4. Click Run all rules.Stratum 4D makes the links and shows the number of linked elements.

To link the selected elements to an activity

  1. In the side panel, click the Selection tab.
  2. Select the elements in the 3D view, or use Select by property.
  3. Select the activity in the Gantt chart.
  4. Under Link selection to activity, click Link.

To link with the keyboard

  1. Select the elements in the 3D view.
  2. Select the activity in the Gantt chart.
  3. Push Ctrl+Shift+A.Stratum 4D links the elements to the activity. It uses the profile that you selected last on the Selection tab.
Stratum 4D keeps the links when you import a new update of the schedule. It finds each activity by its Activity ID.

Split an element into parts

A model element can be larger than one unit of work. For example, one slab can have three pours, and one wall can have bays and lifts. You can split the element in Stratum 4D. You do not have to change the model. Each part then links to its own activity.

  1. Select the element in the 3D view.
  2. In the side panel, click the Tools tab.
  3. Under Split into pours / bays, select the Split type:
    • Equal parts along one axis: select the axis and type the number of parts.
    • At positions along one axis (uneven): select the axis and type the cut positions in percent, for example 30, 60.
    • Grid: columns × rows × layers: type the number of columns (X), rows (Z) and layers (height).
  4. Type a name for the parts, for example Pour.
  5. Click Split selection.The parts replace the element. The links of the element go to each part.

To put the element back as one part, select a part and click Unsplit. A growth profile, for example Bottom up, grows each part in its own space.

Appearance profiles

An appearance profile tells how an element looks before, during and after its activity. Stratum 4D has these standard profiles:

ProfileBefore the activityDuring the activityAfter the activity
InstallNot visibleShows in the color of the work, and growsShows in its own color
RemoveShows in its own colorShows in the color of the workNot visible
TemporaryNot visibleVisible, for example scaffoldingNot visible

To change a profile, or to make a new profile, click the Profiles tab. Under Appearance profiles, you can set the colour, the transparency and the growth direction for each phase. For example, set the growth to Bottom up for a wall, or West → east for a slab.

Play the simulation

  1. In the playback bar, click the play button, or push Space.The playback date moves forward. The model, the Gantt chart and the date change together.
  2. To change the speed, use Speed.
  3. To go to one date, drag the line in the Gantt chart, or use the back and forward buttons.

On the Display tab, under Dates to simulate, select Current schedule (actuals + forecast) or Baseline (P6 target dates). Play the two to compare the plan with the forecast. Under Colour by, select one of these modes:

  5. Move the camera. Then click the Camera channel at the same time, or click Key camera.A blue key shows on the channel.
  6. Do steps 4 and 5 again for each camera position.
  7. To see the result, click Preview.

9AI assistants (MCP)

This chapter tells you how to connect an AI assistant to Stratum 4D, and what the assistant can do with your schedules.

What the MCP server does

MCP (Model Context Protocol) is a standard that lets an AI assistant use tools on your computer. The Stratum MCP server gives the assistant the Stratum 4D engine. You ask a question in usual words, for example "Open the last XER and tell me what slipped". The assistant then uses the Stratum tools to find the answer.

The Stratum MCP server sends no data to other computers. But the assistant application sends your questions and the tool results to its AI service. Obey the data rules of your company before you use an assistant with project data.

What the assistant can do

ToolUse
open_fileOpen a P6 .xer, a Microsoft Project .xml or a .stratum.json file
list_projects, open_projectList and open the projects in the database of the desktop application
summary, list_openDates, counts, status and critical activities of an open schedule
list_activities, get_activityFind activities by text, status, dates or float, and show all data of one activity
scheduleCalculate the schedule (F9), with a new data date if necessary
critical_path, lookaheadThe critical path, and the work that starts or finishes in the next days
kpis, kpi_activitiesSPI, CPI, BEI, finish variance and the DCMA checks, with the activities of each count
check_scheduleThe quality check of Chapter 5
compareThe changes between two schedules
update_activity, update_progressRecord the progress of one activity, or update all activities as planned to a new data date
exportMake a P6 XER, a Microsoft Project XML, a CSV or a Stratum file
save_projectSave the project in the database as a new version

Install the MCP server

You must have Node.js 20 or a newer version. You can get it from nodejs.org.

  1. On the release page of Stratum 4D, download the file Stratum-4D-<version>-mcp.zip.
  2. Extract the file to a folder that you keep, for example C:\Stratum\mcp.
  3. Make sure that stratum-mcp.cjs and sql-wasm.wasm are in the same folder.

To connect Claude Desktop

  1. In Claude Desktop, click Settings › Developer › Edit Config.The file claude_desktop_config.json opens.
  2. Add the lines that follow. Use your folder. On Windows, write each \ two times. 
    {
  "mcpServers": {
    "stratum-4d": {
      "command": "node",
      "args": ["C:\\Stratum\\mcp\\stratum-mcp.cjs"]
    }
  }
}
  3. Save the file and start Claude Desktop again.The tools list of the chat shows the Stratum tools.

To connect Claude Code

Type this command. Use your folder.

claude mcp add stratum-4d -- node /path/to/stratum-mcp.cjs

Add --scope user to use the server in all your projects. For a different MCP client, start node stratum-mcp.cjs as a stdio server.

The project database

The MCP server finds the database of the desktop application at these locations:

SystemFile
Windows%APPDATA%\Stratum 4D\stratum.db
macOS~/Library/Application Support/Stratum 4D/stratum.db
Linux~/.config/Stratum 4D/stratum.db

To use a different file, set the environment variable STRATUM_DB in the configuration of the server.

Close the desktop application before you tell the assistant to save a project. If the two save at the same time, one of the saves can fail. Reading is safe while the desktop application is open.

Safety settings of the MCP server

The text in a schedule file comes from other persons. A person can write an instruction to an assistant in an activity name or a note. The Stratum MCP server tells the assistant that this text is data, not an instruction. If a result contains text that looks like an instruction, the server adds a note to the result.

The server also writes each tool call to a log file on your computer: ~/.stratum/mcp-ledger.jsonl. Each line contains a fingerprint of the line before it. Thus a changed line or a removed line shows when you check the file.

Setting (environment variable)Effect
STRATUM_MCP_READONLY=1The server does not write files or the database. export and save_project stop with a message.
STRATUM_MCP_ROOTSThe server reads and writes files only in these folders. On Windows, put ; between the folders.
STRATUM_MCP_LEDGERA different file for the log of tool calls, or off to stop the log

To set the safety settings for Claude Desktop

  1. Open claude_desktop_config.json as in the procedure above.
  2. Add an env part to the stratum-4d server. Use your folders. 
    "stratum-4d": {
  "command": "node",
  "args": ["C:\\Stratum\\mcp\\stratum-mcp.cjs"],
  "env": {
    "STRATUM_MCP_ROOTS": "C:\\Projects\\Schedules",
    "STRATUM_MCP_READONLY": "1"
  }
}
  3. Save the file and start Claude Desktop again.

To check the log of tool calls

  1. Open a terminal in the folder of the MCP server.
  2. Type node stratum-mcp.cjs --verify-ledger.The result shows the number of entries, and intact or the first entry that is not correct.
These settings make a hidden instruction easy to see. They cannot stop all of them. Do not let export and save_project run without a question.

Examples of questions

  • "Open C:\Schedules\Update 12.xer. What is the finish date? Which activities are on the critical path?"
  • "Compare update 11 and update 12. Which activities slipped more than 5 days?"
  • "Do a schedule check and list the open activities that have no successor."
  • "Give me a three-week look-ahead for the civil works."
  • "Set C-4010 to 60% complete with an actual start of 3 November. Update the progress to 10 November, schedule, and export an XER."

The assistant application shows each tool call before it runs, unless you let the tool run without a question. Do a check of each change before you let it run.

10Stratum Server: users, security and AiSOC

This chapter is for the administrator of a Stratum Server. It tells you how to manage users, approve updates to P6, read the audit log, and connect the server to AiSOC.

Users and roles

Each person signs in to Stratum Server with an email address and a password. The role of the user sets what the user can do.

RoleWhat the user can do
AdminAll work. Manage users, settings, security, approvals and the AiSOC connection.
PlannerChange projects, dashboards and reports. Ask for an update to P6.
ViewerRead projects and dashboards. Get reports by email.

To add or change a user

  1. Click Settings, then the Users tab.
  2. Click + Add user, or click edit on the line of the user.
  3. Type the name and the email address. Select the role.
  4. For a new user, type a password of 8 characters or more.
  5. In Reason, type why you make the change.The audit log keeps the reason.
  6. Click Save.
A new password or a new role stops the other sessions of the user at once. The user must sign in again.
The server must have one admin at all times. You cannot remove the only admin, or change the role of the only admin. First, make a different user an admin.

Sign-in protection

After 5 incorrect passwords from one computer, Stratum Server locks the sign-in of that account from that computer for 15 minutes. After 10 incorrect passwords from all computers, it locks the account for 15 minutes. The sign-in page shows the time to wait. Each incorrect password and each lock goes into the audit log.

If the server is behind a reverse proxy, set STRATUM_TRUST_PROXY=1 on the server. Then the server sees the address of each user, not the address of the proxy.

Approve updates to P6

An update to P6 changes data in a different system. Thus Stratum Server can keep each update until an administrator approves it. The administrator sees what the update contains, and approves only that content.

Rule (Settings › Security)PlannerAdmin
Planners ask; an admin approvesThe update waits for approval.The update goes to P6 at once.
Everyone asks; an admin other than the requester approvesThe update waits for approval.The update waits. A different admin must approve it.
No approvalThe update goes to P6 at once.The update goes to P6 at once.

The first rule is the default.

To set the rule

  1. Click Settings, then the Security tab.
  2. In Sending progress to Primavera P6, select the rule.The server saves the rule at once. The audit log keeps the old rule and the new rule.

To ask for an update (planner)

  1. Open the project that you imported from P6.
  2. In the P6 layout, click Project › Send Progress to P6. In the other layouts, click Update P6.
  3. Click OK.The status bar shows Sent for approval. Nothing goes to P6 yet.

To approve or reject an update (admin)

  1. Click Settings, then the Security tab.The table shows the requests that wait.
  2. Click review on the line of the request.
  3. Read the summary: the project, the number of activities, the started and finished activities, and the data date.
  4. To send the update, click Approve and send.Stratum Server sends the progress to P6 and shows the number of activities.
  5. To stop the update, type a reason. Then click Reject.
The request keeps a fingerprint (SHA-256) of the update. If a person changes the stored update after the request, the server does not approve it. The requester can cancel their own request.

The audit log

The audit log is a list of all sign-ins and all changes on the server. Each entry has the time, the user, the computer address, the action and the details. Passwords are not in the log. The log records only that a password changed.

Each entry contains a fingerprint of the entry before it. Thus a changed entry or a removed entry breaks the chain, and a check of the log finds it. The database also refuses to change the entries.

To read and check the audit log

  1. Click Settings, then the Security tab.
  2. In Show, select the type of entries, for example Sign-ins.
  3. Click Verify the log.A green line shows that all entries are correct. A red line shows the first entry that is not correct.
  4. To give the log to an auditor, click Export CSV.
If the check shows a red line, do not change the database. Tell your security team. Keep a copy of the database and of the server log for the investigation.

Stratum Server also checks the log when it starts and one time each day. It writes the result and the last entry to its own log, outside the database. A chain cannot show that entries were cut from its end. Compare the last entry in the server log with the last entry that Verify the log shows.

To keep the log for a limited time

  1. On the Security tab, go to Keep audit entries.
  2. Select the period, for example 2 years.Each day, the server removes the entries that are older than the period.

Before it removes entries, the server writes a checkpoint. The checkpoint records how many entries went and the fingerprint of the last one. Thus the check of the log continues to work after the removal.

Connect to AiSOC

AiSOC is an open-source security operations center that you install on your own server. Stratum Server can send its audit events to AiSOC. Then your security team sees Stratum with the other systems of the company. AiSOC is a separate project, and Miqyas Labs is not related to it.

By default, Stratum sends only the security events. These are sign-ins, locks, changes to users and settings, approvals, updates to P6, and the checks of the audit log. Each event has a severity. For example, a locked sign-in is high, and a broken audit log is critical.

To install AiSOC

It is necessary to have a server with Docker, 8 GB of memory and 20 GB of free disk. Your IT team can do these steps.

  1. On the server, type git clone https://github.com/beenuar/AiSOC.
  2. Type cd AiSOC, then make up.AiSOC starts. It shows the address of the console and the administrator password.
  3. In the AiSOC console, add a connector for Stratum. Click Reveal push URL.AiSOC shows the push token.

To connect Stratum Server to AiSOC

  1. Click Settings, then the AiSOC tab.
  2. Type the address of the AiSOC console, for example https://aisoc.company.local:3000.
  3. Type the ingest address, for example https://aisoc.company.local:8081.
  4. Type the push token and the tenant ID from AiSOC.
  5. Select Send Stratum audit events to AiSOC.
  6. Click Save.
  7. Click Send a test event.A green line shows that AiSOC accepted the event.

To open the AiSOC console

  1. Click Settings, then the AiSOC tab.
  2. Click Open AiSOC console.The AiSOC console opens in a new tab.
  3. Sign in with your AiSOC account.
If AiSOC is not available, Stratum keeps the events and sends them again later. The AiSOC tab shows the number of events that wait and the last error. To send them at once, click Send waiting events now.
Keep the push token secret. Stratum Server keeps it encrypted and does not show it again. If you think that a different person has the token, make a new token in AiSOC and type it here.
