The P6 layout

This chapter tells you how to use the P6 layout to plan, schedule, update and check a project.

Parts of the P6 layout

The P6 layout has the same parts as Primavera P6 Professional. If you know P6, you can use this layout immediately.

PartWhereUse
Menu barTopFile, Edit, View, Project, Enterprise, Tools and Help menus
Window tabsBelow the toolbarProjects, WBS, Activities, Assignments, Resources, Tracking and more

Make the activities

To add an activity

  1. In the activity table, select a row in the applicable WBS.
  2. Push Ins, or click Edit › Add.A new activity row shows below the selected row.
  3. Type the Activity Name.
  4. Type the Original Duration in days.

To link activities

  1. Select the activities in the sequence of the work. Hold Ctrl to select more than one.
  2. Push Ctrl+L, or click Edit › Link Activities.Each activity becomes the predecessor of the next activity, with a Finish to Start relationship.

To set a different relationship type (FS, SS, FF or SF) or a lag, open the Predecessors tab in the bottom pane. Then change the type or the lag of the relationship.

To assign resources

  1. Select the activity.
  2. Click Edit › Assign Resources….
  3. In the row of the resource, click Assign.The resource is assigned to all the selected activities.
  4. Click Close.
  5. In the Resources tab, type the Budgeted Units for each resource.

Schedule the project

The scheduler calculates the early and late dates and the total float of each activity. It uses the logic, the durations, the calendars and the constraints. It starts at the data date.

To schedule the project

  1. Push F9, or click Project › Schedule….The Schedule dialog opens.
  2. Make sure that Current Data Date is correct.
  3. Click Schedule.The dates and the float change. The critical activities show in red.
  4. To see the result of the calculation, click View Log.

To change the rules of the calculation, click Options… in the Schedule dialog. For example, you can set retained logic or progress override, and the definition of a critical activity.

Stratum 4D uses the same calculation rules as P6. If you import an XER file and schedule it with the same options, the dates are the same as in P6. If a date is different, look at the schedule log first.

Set and compare baselines

A baseline is a copy of the project at one time. You compare the current schedule with the baseline to see the slip.

To make a baseline

  1. Click Project › Maintain Baselines….
  2. Click Add.A copy of the current project becomes a new baseline.
  3. Type a name for the baseline.
  4. To compare the project with this baseline, click Assign as Project Baseline.
  5. Click Close.

To see the baseline bars on the Gantt chart, click View › Show Baseline Bars. To use a baseline from a different file, click Assign from file… and select the XER or XML file.

Update the progress

Each update period, you record the actual progress. Then you move the data date and schedule again. Figure 5-4 shows the cycle.

To record the progress of an activity

  1. Select the activity.
  2. In the bottom pane, click the Status tab.
  3. Set Status to In progress or Complete.
  4. Type the Actual start date. For a complete activity, also type the Actual finish date.
  5. For an activity in progress, type the % complete and the Remaining (days).

To update all the activities as planned

Use this procedure if the work went as planned. It sets the actual dates and the progress from the planned dates.

  1. Click Tools › Update Progress….
  2. Type the New data date.
  3. Select All activities, or Selected activities only.
  4. Click Apply.
  5. Push F9 to schedule the project.
Update Progress changes the actual dates of many activities. Do a check of the result before you send the schedule to other persons. To go back, push Ctrl+Z.

Check the schedule

To do a quality check

  1. Click Project › Check Schedule….The dialog shows each check with the number of activities that do not pass.
  2. Click a check to see its activities.
  3. Correct the activities. Then do the check again.

The checks include missing predecessors and successors, hard constraints, negative float, high float, long durations, leads and lags.

To compare two schedules

  1. Click Tools › Claim Digger (compare schedules)….
  2. Open the project of this update. Stratum 4D uses it as the Current schedule.
  3. For the Base schedule, select a stored baseline. Or click Choose… and select the file of the last update.The report lists the changed, added and deleted activities, and the changed relationships.
  4. To keep the report, click the download button.

Send the result

If you imported the project from a P6 connection, click Project › Send Progress to P6 to send the progress directly. On a Stratum Server, an administrator can approve this update first (Chapter 10).

To send the schedule back to P6 as a file, click File › Export… (XER). To send it to Microsoft Project, click File › Export… (Microsoft Project XML). To print, push Ctrl+P. Chapter 4 gives the procedures.
