# Brand identity and credit

Approved name: **Struxelo 4D**.  
Concept and product direction: **Junaid Quamar, Senior Planning Engineer**.

Junaid supplied the navy-and-amber Struxelo 4D brand sheet. Application assets were prepared from that visual reference using image extraction. They are raster adaptations, not a claim to possess the original vector artwork.

- `public/brand/struxelo-wordmark.png`: navy horizontal wordmark for light backgrounds.
- `public/brand/struxelo-icon.png`: navy rounded-square 4D icon.
- `public/brand/struxelo.ico`: Windows icon format with multiple sizes derived from the icon asset.

The wordmark appears in the workspace header, About panel and documentation cover. The square mark is used for the browser favicon, desktop window icon and packaged executable resource.

Use navy as the main navigation and action color, amber for brand accents, teal for completed work and blue for selection. Progress colors must also be described in text so color is not the only signal. Do not distort the logo or place the navy wordmark on a navy background.
